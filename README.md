# 批量处理助手（Windows）

工具现在包含两种独立工作方式：

- **文件夹批量**：读取输入目录第一层的全部视频，按所选压缩档位批量输出为 720×1280 或 1080×1920 MP4，不需要打开剪映。
- **剪映草稿**：与剪映专业版同时运行。剪映负责渲染滤镜、文字、特效、贴纸和全部可见轨道；工具按主视频轨道逐段导出，再统一做竖版与倍速处理。

## 同事分发与免安装包

双击 `发布免安装包.cmd` 会生成：

- `release\批量处理助手-免安装版-win-x64\`：可直接复制的完整文件夹。
- `release\批量处理助手-免安装版-win-x64.zip`：建议直接发给同事的压缩包。
- 同名 `.sha256.txt`：用于校验传输后的文件完整性。

该发布物为 Windows x64 自包含单文件应用，已经携带 .NET 8 Desktop Runtime、FFmpeg、`jy-draftc`、水印和使用说明。目标电脑无需安装 .NET 或 FFmpeg；但“剪映草稿”模式仍需安装剪映专业版。

首次运行时输入目录和输出目录为空，水印路径显示为相对路径 `watermark.png`。设置、启动日志、草稿解析缓存以及自动生成的剪映解析配置按 Windows 用户保存在 `%LocalAppData%\JianyingBatchExporter`，不会写入或混入免安装包。

## 已实现

- 兼容本机剪映专业版 11.0.0 的加密草稿只读解析。
- 自动发现本地草稿、视频轨道与主轨道片段。
- 三种竖版模式：完整画面加黑边（默认）、居中裁切、模糊背景填充。
- 文件夹批量支持不旋转、顺时针或逆时针 1°～359° 整数角度旋转，90%/100%/110%/120% 中心缩放，以及明亮、鲜艳、暖色、冷色、黑白五种单选轻量滤镜。
- 旋转、缩放、滤镜、竖版适配、倍速和水印合并在同一次 FFmpeg 转码中执行；90°/180°/270° 自动走快速旋转路径，缩放使用快速双线性算法，模糊背景采用低分辨率预处理后再铺底。
- 旋转、缩放、滤镜、播放速度、输出压缩以及视频/音频码率统一放在“处理参数”卡片；草稿模式保留倍速、压缩和码率选择，文件夹专用画面选项会自动置灰。
- 1.0x、1.1x、1.25x 预设倍速，以及 0.1x～5.0x 自定义倍速；视频与音频同步变速。
- 输出分辨率可选 576P（默认）、720P、1080P；切换分辨率时分别推荐视频 2500/4000/6000 kbps、音频 128 kbps，推荐后仍可手动调整。
- 视频码率可选 500、800、1000、1500、1600、2000、2500、3000、4000、5000、6000、8000 kbps；音频码率可选 64、96、128、160、192、256、320 kbps，不再提供自动档。TikTokNew_5 实测 1600/128 输出 13.68 MiB。
- 为全部成品统一叠加可替换的图片水印，默认随应用提供一张透明 PNG。
- 扫描普通输入目录中的 MP4、MOV、MKV、AVI、WEBM、WMV、FLV、TS、MTS、M2TS 文件并顺序处理。
- 文件夹模式直接输出到指定目录；单个文件失败不会中断其余任务。
- 处理完成后显示并记录本次总耗时，再自动打开成品目录；“清理记录”可清空日志并重置进度与任务状态，同时保留当前列表和选择。
- 批处理管线已通过 100 个真实 MP4 连续转码压力测试；每个文件都有独立状态，停止任务时会终止 FFmpeg 并清理未完成临时文件。
- 安全预览首段：只设置剪映导出区域，不修改草稿、不开始导出。
- 自动逐段导出、命名、等待剪映渲染，并执行竖版/倍速后处理。
- 原始导出保留在 `_jianying_raw`，成品写入 `成品`，不会覆盖已有文件。
- 剪映导出完成后会同时检查文件大小稳定和文件写锁释放，避免把仍在写入的文件提前交给后处理。

## 文件夹批量处理

1. 双击 `启动工具.cmd`，默认进入“文件夹批量”。
2. 选择输入目录，工具会立即扫描其中第一层的全部视频。
3. 默认选择“完整画面加黑边”，也可切换为居中裁切或模糊背景填充。
4. 按需选择旋转方向并输入 1～359° 整数角度，再设置缩放、滤镜、倍速、输出压缩、视频/音频码率、图片水印和输出目录。
5. 点击“开始批量处理”。所有成品直接写入输出目录，同名文件会自动增加序号。
6. 任务结束后，程序会自动打开成品输出目录。

## 剪映草稿分段导出

1. 双击 `启动工具.cmd`。
2. 左侧切换到“剪映草稿”，并在剪映中打开目标草稿停留在编辑页面。
3. 工具内选择草稿和作为分段依据的主视频轨道。
4. 标定时间线位置。
5. 点击“打开剪映导出设置”，把剪映的导出目录设为工具提示的 `_jianying_raw` 目录，并设置 MP4 / 1080P。
6. 保持导出窗口打开，分别标定文件名输入框和最下面的“导出”按钮，然后按 Esc 返回编辑页面。
7. 先点击“在剪映中预览首段”，确认灰色导出区域与第一段边界一致。
8. 点击“开始自动导出”。运行期间不要操作鼠标键盘或改变剪映窗口布局。

## 安全边界

- 工具只解密并读取草稿副本，不回写 `draft_content.json`，也不注册或创建临时草稿。
- 所有导出操作通过剪映的入点、出点和导出界面完成，因此剪映滤镜与多轨叠加由剪映原生渲染。
- 竖版模式应用于剪映导出的完整合成画面；居中裁切可能裁到靠近左右边缘的文字或贴纸。
- 剪映升级或界面布局变化后需要重新标定坐标。
