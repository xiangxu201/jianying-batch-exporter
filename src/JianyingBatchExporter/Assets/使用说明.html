DESKTOP 2.9

批量处理助手

文件夹批量视频处理与剪映草稿自动分段导出的离线使用说明。

一、开始前准备

FFmpeg

文件夹批量和最终竖版处理依赖 FFmpeg。左下角“运行环境”显示“FFmpeg 可用”后才能开始。

剪映

只有“剪映草稿”模式需要安装并打开剪映。自动导出期间不要操作鼠标和键盘。

输出规格

默认输出 720 × 1280 高效压缩 MP4；也可选择 1080 × 1920 高清输出。音频编码均为 AAC。

二、文件夹批量处理

  1. 进入“文件夹批量”，选择包含原始视频的目录。
  2. 点击“扫描”，确认右侧出现全部待处理文件。
  3. 选择画面适配方式；按需设置旋转、缩放、单选滤镜，再设置播放速度、输出压缩、视频/音频码率、水印与输出目录。
  4. 点击“开始批量处理”，确认参数后等待完成。
  5. 任务结束后，程序会自动打开成品输出目录。

程序只扫描输入目录第一层，不会递归处理子目录；已有同名成品不会被覆盖，而是自动生成新文件名。

三、剪映草稿分段导出

  1. 在剪映中打开需要处理的草稿，再进入软件的“剪映草稿”页面。
  2. 选择草稿和作为分段依据的主视频轨道。
  3. 首次使用或剪映布局改变后，完成时间线、文件名输入框、导出按钮三项标定。
  4. 可先点击“预览首段”检查区间，再点击“开始自动导出”。
  5. 剪映原生渲染完成后，程序会进行竖版、倍速和图片水印处理，并自动打开“成品”目录。

自动导出期间不要移动鼠标、切换窗口或使用键盘，否则剪映自动点击位置可能失效。

四、处理参数设置

设置说明
处理参数卡片旋转、缩放、滤镜、播放速度、输出压缩以及视频/音频码率集中显示；剪映草稿模式仍可设置倍速、压缩和码率，文件夹专用的画面选项会自动置灰。
完整画面加黑边默认选项；保留完整画面，剩余区域填黑。
居中裁切铺满当前档位的 9:16 画布，横版素材可能裁掉左右内容。
模糊背景填充保留完整主体，使用放大模糊画面填充空白区域。
选择规则三种方式最多选择一种；再次点击已选项可取消。开始处理前必须选择一种。
旋转仅文件夹批量可用：选择顺时针或逆时针，并输入 1°～359° 的整数角度；旋转后再执行竖版适配。
中心缩放仅文件夹批量可用：90%、100%、110%、120%；90% 会居中并在四周留黑边。
轻量滤镜仅文件夹批量可用：无、明亮、鲜艳、暖色、冷色、黑白；一次只能选择一个，水印颜色不受影响。
处理速度所有画面调整合并在一次 FFmpeg 转码中；90°、180°、270° 自动走快速旋转路径；缩放使用快速双线性算法；模糊背景先在低分辨率完成模糊，再放大铺底，主体仍以完整分辨率处理。
预设倍速可直接选择 1.0x、1.1x 或 1.25x。
自定义倍速选择“自定义”后输入数值，支持 0.1x–5.0x，视频与音频同步变速。
输出压缩可选 576P（默认）、720P、1080P。切换分辨率时会分别推荐视频 2500、4000、6000 kbps，音频均推荐 128 kbps；推荐后仍可手动调整两个码率。软件直接使用随包 FFmpeg，不要求安装 AfterCodecs 或 Adobe 软件。
视频码率500、800、1000、1500、1600、2000、2500、3000、4000、5000、6000、8000 kbps，不再提供自动档。数值越低通常体积越小，但画质也会降低。
音频码率64、96、128、160、192、256、320 kbps，不再提供自动档。TikTokNew_5 样片选择视频 1600、音频 128 后输出 13.68 MiB，接近原片 13.61 MiB。

五、图片水印

  • 默认启用随软件发布的透明水印图片。
  • 点击“浏览”可以换成自己的 PNG、WebP、JPG、JPEG 或 BMP。
  • 建议使用与所选档位一致的 720×1280 或 1080×1920 透明 PNG；图片会按最终画布等比适配并居中覆盖。
  • 启用水印但文件丢失时，程序会在开始前提示重新选择，不会静默输出无水印视频。

六、运行记录与完成目录

  • “运行记录”显示扫描、FFmpeg、剪映导出与错误信息。
  • 每次任务从确认开始后计时；完成、停止或异常时，运行记录会保存本次总耗时，成功时也会显示在进度区和完成弹窗中。
  • 点击“清理记录”会清空日志、重置进度和每条任务状态，但保留当前文件列表、草稿及轨道选择。
  • 任务成功结束后会自动打开对应成品文件夹。
  • 停止任务时，已经完成的成品会保留。

  2. 同事必须先完整解压 ZIP，不能直接在压缩包预览窗口中运行。

  5. 首次运行时输入目录和输出目录为空；默认水印显示相对路径 watermark.png，以后可点“浏览”改为本机图片。

免安装包面向 64 位 Windows 10 22H2 及以上系统。剪映草稿模式仍要求电脑已安装剪映专业版；文件夹批量模式不需要剪映。

八、常见问题

提示“未找到 FFmpeg”

确认 FFmpeg 已安装或软件发布目录中的工具文件完整，然后重新启动程序。

剪映自动点击位置不正确

保持剪映窗口布局与缩放稳定，重新执行三项界面标定。

自定义水印没有生效

确认“为所有成品视频叠加图片水印”已勾选，并检查所选图片路径仍然存在。

速度大于 2 倍后音频是否同步

会同步。程序会自动把音频变速拆成 FFmpeg 支持的多段处理，最高支持 5 倍。
