批量处理助手 2.9 · Windows x64 免安装版

使用方法
1. 将收到的 ZIP 完整解压到一个普通文件夹，不要直接在压缩包内运行。
2. 双击“批量处理助手.exe”。
3. 文件夹批量模式可直接使用；剪映草稿模式仍需要目标电脑安装剪映专业版。
4. 首次运行时输入目录和输出目录为空，请使用者自行选择。
5. 默认水印显示相对路径 watermark.png；以后可点“浏览”选择本机图片。
6. 默认选择“高效压缩 720P（推荐）”，体积接近 AfterCodecs H264 Q70 S5；需要更高清晰度时可选择“高清输出 1080P（体积较大）”。
7. 可手动选择视频码率 500～8000 kbps、音频码率 64～320 kbps；测试 TikTokNew_5 可先选视频 1600、音频 128。

运行环境
- 支持 64 位 Windows 10 22H2 及以上版本，推荐 Windows 11。
- 本包已经包含 .NET 8 桌面运行时、FFmpeg 和剪映草稿读取工具，无需额外安装这些组件。
- 请保持 exe、watermark.png、使用说明.html 和 tools 文件夹的相对位置不变。

安全提示
- 当前内部版本没有购买代码签名证书。若 Windows SmartScreen 提示未知发布者，请先确认文件来自可信同事，再选择“更多信息”→“仍要运行”。
- 第一次启动可能比后续启动稍慢，这是单文件自包含程序解压运行组件的正常现象。

帮助
- 软件左下角点击“使用说明”，会在默认浏览器中打开完整操作文档。
- 如需更换默认水印，可在软件中点击图片水印旁的“浏览”。
